This is a simple event list guest manager System developed using PHP, css and html. The system allows users to store and manage list of guest easily.
Features a)Dashboard: View, edit, and delete name emails and event and save it. 

Project File Structure This project contains six (4) main files: 
i)fetch_guest.php – for entering details of guest
ii)save_guest.php – save details page. iii)index.html it provide structure of web pages vi)style.css – Stylesheet for the system interface.

Setup Guide Follow these steps to run the system on your computer:

i)Start the Server Make sure both Apache is running through XAMPP
ii)Place the Project Files Copy the project folder and paste it inside: htdocs (for XAMPP)
iii)Open your browser and enter: http://localhost/Event list system /
